## Accurate short copy

**English:** Divan is an open-source Codex plugin with seven portable Agent Skills. Describe a software task in natural language; Divan guides project inspection, implementation, review, and verification. [Install and try it](../README.md#install).

**Türkçe:** Divan, yedi taşınabilir Agent Skills içeren açık kaynak bir Codex eklentisidir. Yazılım işini doğal dille anlat; Divan proje inceleme, uygulama, gözden geçirme ve doğrulama akışına yardımcı olur. [Kur ve dene](../README.tr.md#kurulum).

The plugin runs in the coding agent's project conversation. It does not ship a standalone application, server, or MCP connection. Repository checks validate the package; real task success and comparative model performance remain to be measured. Do not advertise an unmeasured speed, accuracy, or completion rate.

## Distribution

- [GitHub repository](https://github.com/trugurpala/divan): source, installation, issue-based task reports, and current prerelease. The social preview is live.
- [Divan website](https://trugurpala.github.io/divan/): English and Turkish product overview with installation routes; GitHub Pages publishes it from `main/docs`.
- [AgenticSkills.io](https://agenticskills.io/): submitted for editorial review; listing is not yet verified. Avoid duplicate submissions.
- [agentskill.sh](https://agentskill.sh/submit): candidate skill directory that imports a GitHub repository's `SKILL.md` files. Verify the live listing after submitting.
- [Show HN guidance](https://news.ycombinator.com/showhn.html): consider a launch post after an independently repeatable real-task example is available.

Paid directory placements require a separate spending decision. Neither a directory submission nor a share image is evidence that Divan appears on GitHub Trending.
