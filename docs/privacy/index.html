Privacy

Last updated 22 October 2026

Divan is an open-source, skills-only coding-agent plugin maintained by Uğur Pala. It has no Divan-operated server, account, analytics, or telemetry. Installing the package does not send your project files to the maintainer.

Your coding workspace

The skills instruct your coding agent to work with the project and tools you authorize. Your agent host and any tools or services you choose may process project content under their own settings and privacy terms. Divan does not control those hosts or collect their conversations, code, or tool results.

Website and feedback

This website uses no Divan analytics, tracking cookies, forms, or third-party scripts. GitHub hosts the site and may process routine visit data under its own privacy statement.

If you voluntarily open a GitHub issue or pull request, GitHub stores and displays what you submit according to the repository visibility and GitHub's policies. Please remove credentials, private code, and personal data before posting. The maintainer uses those reports to respond to the request and improve Divan. GitHub and the maintainer are the recipients; there is no separate Divan feedback database.

Divan retains no project data. Public GitHub contributions remain until removed under GitHub's controls or by the maintainer. Support email remains in the maintainer's mailbox until deleted; no fixed deletion period is promised. You can edit or close your own GitHub contributions, and ask the maintainer to review a removal request.

Contact

For support or privacy questions, use the Divan issue form without private data, or email mail@ugurpala.com. For an existing public report that contains sensitive information, contact the maintainer privately so it can be reviewed.
