# Divan v0.18.2 Local Seyir Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a secure, bilingual, read-only local progress page that opens from the canonical Divan CLI on a real loopback URL.

**Architecture:** Build one immutable status snapshot from existing goal receipts, route artifacts, task Markdown, and local Git; do not create a second state machine. Serve static standard-library assets and a protected JSON endpoint from the existing `api` module, with an ephemeral port and fragment-held capability token.

**Tech Stack:** Python 3.11+ standard library, `unittest`, `http.server.ThreadingHTTPServer`, static HTML/CSS/vanilla JavaScript.

## Global Constraints

- The product name remains `Divan`; `Company OS` and `Project OS` are compatibility terms only.
- The server binds only to IPv4 loopback `127.0.0.1`.
- The server is read-only and exposes only `GET` and `HEAD`.
- No React, Node.js, npm, database, telemetry, cloud control plane, or third-party Python dependency.
- Machine-facing commands, JSON keys, and file names are canonical English and ASCII.
- Reader-facing text is complete in Turkish and English from one validated catalog.
- Absolute paths, secrets, environment values, prompts, and raw command output are excluded from status responses.
- User-controlled content is rendered with `textContent`, never `innerHTML`.
- The server selects a real free port; documentation never presents an example URL as live.

```python
SUPPORTED_LANGUAGES = ("en", "tr")
FIELD = string.Formatter()

def placeholders(value: str) -> frozenset[str]:
    return frozenset(
        field for _, field, _, _ in FIELD.parse(value) if field is not None
    )

def load_messages(directory: pathlib.Path) -> dict[str, dict[str, str]]:
    value = json.loads((directory / "messages.json").read_text(encoding="utf-8"))
    if not isinstance(value, dict) or not value:
        raise ValueError("message catalog must be a non-empty object")
    for key, translations in value.items():
        if set(translations) != set(SUPPORTED_LANGUAGES):
            raise ValueError(f"message locale parity failed: {key}")
        if placeholders(translations["en"]) != placeholders(translations["tr"]):
            raise ValueError(f"message placeholder parity failed: {key}")
    return value
```

```python
def build_snapshot(project, language="auto", now=None):
    root = pathlib.Path(project).resolve()
    if not root.is_dir():
        raise ValueError(f"project directory does not exist: {root}")
    locale = locales.resolve_language(language)
    goal = _latest_goal(root)
    git = _git_snapshot(root)
    return {
        "schema_version": 1,
        "product": {"name": "Divan", "version": _version()},
        "locale": locale,
        "project": {"name": root.name, **git},
        "goal": _goal_summary(root, goal),
        "current": _current_phase(root, goal),
        "tasks": _tasks(root, goal),
        "checks": _checks(root, goal),
        "evidence": _evidence(root, goal),
        "blocker": _blocker(root, goal),
        "next_action": _next_action(root, goal),
        "generated_at": _utc_timestamp(now),
    }
```

```python
def start_server(project, language, idle_timeout=1800.0):
    token = secrets.token_urlsafe(32)
    server = _SeyirServer(
        ("127.0.0.1", 0),
        _handler(project.resolve(), language, token),
    )
    port = server.server_address[1]
    thread = threading.Thread(target=server.serve_forever, daemon=True)
    thread.start()
    return ServerSession(
        server=server,
        thread=thread,
        url=f"http://127.0.0.1:{port}/session/#{token}",
        token=token,
    )
```

The handler must allow only `/session/`, the three exact static asset paths, and
`/api/status`; reject dot segments, encoded traversal, unexpected Host, CORS
preflight, missing capability, and all mutation methods. Add `Cache-Control:
no-store`, `Content-Security-Policy`, `X-Content-Type-Options: nosniff`,
`Referrer-Policy: no-referrer`, and `X-Frame-Options: DENY`.
