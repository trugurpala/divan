# Company OS compatibility page

`Company OS` was the public name used for Divan's routing layer through
v0.16. The product is still **Divan**; the canonical v0.17 architecture is now
documented as [Divan Engine and Governance Model](Divan-Engine.md).

The old `plugins/sadrazam/company/` import path and `company-validate` CLI alias
remain compatible through v1 and will not be removed before v2.
