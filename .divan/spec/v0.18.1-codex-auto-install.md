# v0.18.1 target — Codex Desktop auto-install

## User result

A Codex Desktop user can run:

```powershell
python scripts/divan.py install --host codex --profile auto --ref v0.18.1 --execute
```

Divan diagnoses the local CLI, selects the strongest provable installation
route, verifies it, states the capability boundary, and prints recovery.

## In scope

- safe process-launch classification,
- explicit `native|auto` install profile,
- native route preservation,
- checksum-backed 41-skill fallback,
- manifest and installed-tree verification,
- deterministic rollback command,
- Turkish/English README, Wiki source, and Pages source synchronization,
- Windows install/remove canary.

## Out of scope

- automatic MCP configuration,
- hidden elevation or ACL repair,
- a second Divan repository,
- external agent runtimes,
- mixed-host fallback transactions,
- claiming skill fallback as native plugin support.

## Acceptance

1. The five CLI diagnoses are distinct and tested.
2. Plain install performs no new probe and preserves its plan.
3. Auto preview writes nothing.
4. Auto execution uses the existing canonical fallback installer.
5. The manifest proves exactly 41 skills, immutable release identity, archive
   SHA-256, and installed tree SHA-256 values.
6. Invalid JSON blocks.
7. User output states limits, rollback, and next action.
8. Unrelated skills survive install and removal.
9. Full local and GitHub quality gates pass.
10. Release assets, provenance, Pages, and Wiki are read back after publication.
