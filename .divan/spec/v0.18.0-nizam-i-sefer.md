# v0.18.0 target — Nizam-i Sefer planning intelligence

## Ferman

Turn a natural-language goal into an explainable, capacity-aware execution
route that survives host changes and long work without making unverified model
or context claims.

## Acceptance

- Preserve the schema-2 route and nine-module architecture.
- Detect an explicit host, `DIVAN_HOST`, bounded official environment hints, an
  ambiguous conflict, or an unknown fallback without storing environment
  values.
- Accept an exact owner-declared context window and label every fallback number
  as a planning assumption rather than a verified product limit.
- Produce deterministic complexity, model class, effort, task dependencies,
  no more than three workstreams, sefer boundaries, handoff rules, commands,
  evidence, and public-surface obligations.
- Suggest GPT-5.6 Sol on Codex only for frontier work and only as a candidate
  whose availability the host must confirm.
- Persist `route.json` with new goals, bind its hash to the receipt, and keep
  old goals and positional APIs valid.
- Execute no target project code, network request, model call, dependency
  install, daemon, or external agent harness.
- Pass focused planning, runtime, engine, goal, provider, CLI, quality, Wiki,
  site, release, and full repository verification.

## Delivery boundary

This slice closes GitHub issue #48 when merged with green CI. It does not claim
that every registered host has a native installer or that v0.18.0 is released.
Those require separate clean-host canaries and publication evidence.
