# Divan Support

**English** · [Türkçe kısa yol](#türkçe-kısa-yol)

Divan is a free, community-maintained project. This page separates questions,
bugs, security reports and proposals so people reach the right place quickly.

## Where should I go?

| Need | Route |
|---|---|
| Usage or installation question | [Discussions Q&A](https://github.com/trugurpala/divan/discussions/categories/q-a) |
| Reproducible bug | [Bug report](https://github.com/trugurpala/divan/issues/new?template=bug.yml) |
| Feature proposal | [Feature proposal](https://github.com/trugurpala/divan/issues/new?template=feature.yml) |
| Documentation correction | [Documentation correction](https://github.com/trugurpala/divan/issues/new?template=docs.yml) |
| Security vulnerability | [Private advisory](https://github.com/trugurpala/divan/security/advisories/new) |
| Existing external repository | [Source candidate](https://github.com/trugurpala/divan/issues/new?template=source-candidate.yml) |
| Original Divan skill | [New skill](https://github.com/trugurpala/divan/issues/new?template=new-skill.yml) |
| Verified clean-room evidence | [Acceptance evidence](https://github.com/trugurpala/divan/issues/new?template=kabul-kaniti.yml) |

## Türkçe kısa yol

Kullanım sorusunu Discussions Q&A alanına, tekrar üretilebilir hatayı hata
formuna, güvenlik açığını yalnız özel bildirime gönderin. Kaynak adayı otomatik
kurulmaz. Genel issue içine token, e-posta, müşteri verisi, mutlak bilgisayar
yolu veya özel depo bilgisi yazmayın.

Hata formundan önce salt okunur `doctor` komutunu çalıştırın. Yalnız redakte
edilmiş sonucu, işletim sistemini, host sürümünü, sabit Divan tag'ini ve en küçük
tekrar üretimi paylaşın.
