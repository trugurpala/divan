# Divan Maintainers

## Maintainer scope

| Maintainer | Scope | Release authority |
|---|---|---|
| Uğur Pala (`trugurpala`) | Product direction, repository administration, security coordination and releases | Yes |

Maintainer access does not bypass tests, provenance, code review or the
publication manifest. Future maintainers are added here through a reviewed pull
request that states their scope. Security reports remain private until a safe
disclosure decision is recorded.
