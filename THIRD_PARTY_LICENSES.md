# Third-party licenses

Divan V2 alpha does not vendor third-party source code, prompts, skills, binaries, or runtime packages.

Design influences are documented in the V2 design research, but the active plugin implementation is original repository content.

Before vendoring or copying third-party material:
- verify the exact source and commit;
- verify the license;
- record attribution here;
- copy only the minimum necessary material;
- add tests proving the integration.
